# Quake Anthology 1.2.4

Performance patch for the shared TypeScript engine for Quake, Quake II,
Quake III, their expansions, and supported rerelease content: lit model
geometry is now retained across frames whenever every input to the
shading is provably unchanged.

## What's faster

Measured on the development laptop; your mileage will vary.

- **Retained lit model geometry.** Model preparation previously
  rebuilt every entity's lit local and world-space vertex arrays on
  every frame. When the pose, surface indices, transform values,
  entity color, unlit flag, and resolved lighting are all identical to
  a previous frame, the exact same arrays are now reused. The
  retention key is conservative by construction: for the Q2-family
  shading path it captures the fully resolved entity light (static
  and dynamic light sampled at the origin, plus infrared, minlight,
  and fullbright terms) together with the shading basis, and it is
  withheld entirely for time-varying cases — shell colors and the
  pulsing-light flag never retain. Q1's old-frame normal blending is
  time-dependent and likewise never retains. A retention miss runs the
  identical original code path, so output is unchanged when nothing
  repeats.
- **Mixed cross-game GL (Q2 rerelease world, Q1 rerelease monsters,
  Q3 player/weapons): median frame 58 ms** over 200 frames, from
  60 ms in 1.2.3 on the same probe, with the largest gains where
  entities hold still or revisit identical poses (idling monsters,
  static pickups, paused or slow scenes) and in shadow passes that
  re-prepare the same transforms.

## Notes

- Saved `images.cfg` still applies after legacy `config.cfg`, so the
  stored value wins for shared preferences; console writes apply
  immediately (unchanged from 1.2.3).

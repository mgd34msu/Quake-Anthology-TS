# Quake Anthology 1.1.8

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. Foreign arsenals now play
on every guest execution kind, not only QuakeC.

## Fixed

- Selecting a foreign arsenal on a Quake III QVM or Quake II native-DLL
  world was refused unless the guest artifact had a complete qualified
  primary interface (reverse-engineered per-artifact profiles). Guests
  without one now run as black boxes: their own game continues untouched
  while the shared engine owns the foreign weapons, and the guest's own
  firing stays silent while a foreign weapon is active — for QVM guests
  at the server-state user-command seam (covering local seats, bots, and
  network seats), for native guests through the existing command gating.
  Artifacts with qualified profiles keep their deep primary integration
  (in-guest inventory, pickups, combat, and weapon decisions).
- The content-load, runtime, and equipment refusal gates behind this are
  removed; hook and offhand-grenade equipment no longer require a
  qualified guest combat interface to launch.

Verified end to end: stock `baseq3` (no primary weapon/combat profile)
plays with the Quake arsenal — foreign weapons are granted, selected,
and consume shared ammunition while the guest runs normally.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.8-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.8`
in the repository. Game data retains its original licensing.

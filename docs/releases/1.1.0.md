# Quake Anthology 1.1.0

Second release of the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. This release unifies the
engine core on one shared foundation, makes the executable find game files on
its own, and fixes several cross-game presentation and crash bugs found while
mixing weapons, movement, and characters between games.

## Included

- One shared foundation under the whole engine, modeled on the C
  quake-anthology primitives: arenas, pools, event rings, bounded queues,
  generational handles, an id index, and bit-exact float and math variants
  parameterized by each source's rounding rules. Legacy duplicate
  implementations were removed, so game differences now sit on the unified
  engine as extensions rather than parallel code paths. See
  [the foundation notes](../foundation.md); relative performance of the
  primitives can be measured with `bun run bench:foundation`.
- Automatic game discovery. The executable looks in its own folder, then the
  folder above it, then Steam libraries, anchoring on the `id1`, `baseq2`,
  and `baseq3` directories that always identify Quake, Quake II, and
  Quake III. Mods and expansions are then located relative to each game.
  `--content-root` overrides discovery, and `--steam` jumps straight to
  Steam library locations.
- QuakeWorld movement is selectable for custom games without a QuakeWorld
  (`qw`) content folder; the movement behavior is engine code and only needs
  the base game.
- Fatal errors now append a stack trace to
  `~/.local/share/quake-typescript/crash.log` to make field crashes
  diagnosable.

## Fixed

- Quake 1 jumping works with existing `+moveup` key bindings, not only
  `+jump`.
- The Quake 1 `end` finale and other intermission views in foreign worlds
  show the character model the player selected (for example the Quake III
  Ranger) instead of the fallback Quake 1 model.
- Crash when a Quake III railgun shot destroyed a Quake 1 explosive box:
  sound updates for entities retired after snapshot capture are now skipped
  instead of aborting the frame.
- The first Quake III railgun shot in a session rendered with a missing
  texture slab. Snapshot weapon events now finish registering their weapon
  media before emitting trails and impacts, so the first shot looks like
  every later shot.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.0-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/qfiles` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

## Known issue and scope

Native DLL gameplay can still suffer low frame rates and stalls, as in 1.0.0.
That remaining performance work is scheduled for a later release.

Saving and loading are accepted for this release. Mod compatibility requires
supported executable interfaces and component declarations; discovering a package
does not prove compatibility. See [mod compatibility](../mod-compatibility.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.0`
in the repository. Game data retains its original licensing.

# Quake Anthology 1.1.10

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. Selected enemies, campaign
travel, and custom guest programs now work across every world program the
engine hosts.

## What's new

- **Foreign enemies on every guest world.** Enemy replacement was silently
  ignored on native Quake II DLL worlds, and unavailable on Quake III QVM,
  TypeScript Q3, and QuakeC worlds. Replaced monsters are now stripped from
  the guest's entity string and admitted as shared TypeScript monsters on all
  of them — classic proxy edicts on 1997 DLLs, rerelease foreign projections,
  guest-spawned proxy entities in QVM worlds with a declared combat profile.
  Monsters whose obligations only the guest can discharge (event targets,
  item drops, triggered dormancy) stay guest-native and are reported in the
  console, never silently swapped; the same happens visibly when a guest has
  no declared combat profile to project shared actors into. Saving and
  loading restores them through the selected-monster checkpoint.
- **Campaign travel across programs.** Traveling between levels used to
  require matching source programs. Q3 and QVM worlds now capture a shared
  health/armor/inventory snapshot, and any destination — Q1, Q2, Q3, QVM, or
  QuakeC — lands a foreign carry through the shared tables after its own
  spawn. Same-program travel keeps its native carry (including QuakeC parms).
- **Custom guests anywhere.** `--q2-game` no longer requires a Quake II
  product: the guest edition is derived from the DLL's PE header (i386
  classic API vs x86-64 rerelease API), so a custom Q2 DLL can host any map.
  `--progs` likewise runs on foreign maps, with player starts synthesized
  where the map has none for the selected mode.

## Fixed

- Restoring a save on a native DLL world could retire shared adjunct actors
  (selected monsters) during the guest world rebind, and a phantom native
  actor could claim a rerelease projection edict alongside its projection.
  Guest rebinds now retire only source-bound edict actors, and projection
  spawns retire the phantom so each edict has exactly one owner.
- The kept-monster report is deferred to the first stepped frame so it
  reaches the console instead of being emitted before presentation starts.

Verified end to end: Quake 1 grunts replace the strogg on `base2` under both
the rerelease DLL and a qualified classic DLL (xatrix), fight and damage the
player, and survive a save/load; the unqualified baseq2 classic DLL keeps its
monsters guest-native and reports why.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.10-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.10`
in the repository. Game data retains its original licensing.

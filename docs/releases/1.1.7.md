# Quake Anthology 1.1.7

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. This release removes the
last launcher refusals on mixed custom games for QuakeC worlds: any arsenal
now plays on any QC program, with no per-mod declarations.

## Fixed

- Selecting a foreign arsenal on a QuakeC world (for example Quake II weapons
  on qdoom, with QuakeWorld movement and a Quake III character) was refused
  with "Selected arsenal requires a qualified original QuakeC weapon stage"
  unless the program was one of two pinned retail artifacts or carried a
  hand-authored declaration. The weapon stage is now derived from the
  program itself — the `weapons.qc`/`client.qc` skeleton every QC program
  keeps (`W_WeaponFrame`, the `player_*` animation families, structural
  next-shot release gates, `PutClientInServer`/`SelectSpawnPoint` in either
  classic or rerelease call shape) — held to the same validation shapes the
  declared path always required. The derivation reproduces both pinned
  retail stages exactly and fully qualifies every QC program in the test
  corpus (retail, expansions, rerelease, and mods).
- The related refusal gates are removed: content load, player admission,
  and the mod weapon handoff no longer reject selected arsenals on QC
  worlds; a NetQuake program with QuakeWorld movement selected plays; a
  client spawn that cannot be derived spawns through the program's own
  flow. Foreign damage keeps the generic id1 multiplier path.
- A generic damage layout observing every function no longer collides with
  the weapon dispatcher's boundary composition on undeclared programs.

Known remaining scope, unchanged from 1.1.6: foreign arsenals on Quake III
QVM and Quake II native-DLL worlds still require a qualified primary
interface for the guest (builtin profiles cover known artifacts); a
universal black-box interposition for unknown guests is in progress.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.7-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.7`
in the repository. Game data retains its original licensing.

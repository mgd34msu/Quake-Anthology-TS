# Quake Anthology 1.1.9

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. QuakeWorld and Quake III
mod guests now take the full custom-game matrix in local play.

## Fixed

- QuakeWorld products (including the QuakeWorld expansion variants) refused
  to launch outside dedicated-server operation. They now play in a local
  graphical session like every other source: the dedicated/deathmatch
  requirements are scoped to serving real QuakeWorld wire clients, and
  QuakeWorld spawn preparation became an admission phase inside client
  admission instead of a step only the network signon performed.
- Quake III mod guests (bytecode server games such as LRCTF) refused
  foreign movement, foreign character, and singleplayer selections. The
  preset and recipe assertions dropped their native-only clauses, and
  local-seat commands are translated to the Q3 wire dialect at both guest
  seams (client prediction and guest think), so any movement provider can
  drive a QVM world. Singleplayer campaigns may launch QVM worlds.

Verified end to end: `q1-quakeworld` deathmatch plays locally, and LRCTF
plays singleplayer with Quake movement and a Quake II character.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.9-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.9`
in the repository. Game data retains its original licensing.

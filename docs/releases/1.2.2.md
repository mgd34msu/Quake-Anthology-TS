# Quake Anthology 1.2.2

Performance patch for the shared TypeScript engine for Quake, Quake II,
Quake III, their expansions, and supported rerelease content.

## What's faster

- **Bot navigation construction on foreign maps: ~92 s → ~26 s** for a Q3
  bot on `e1m1`. Q1 clip solids are now prepared once per hull (free-space
  decomposition and expanded separating planes computed a single time and
  spatially indexed) instead of being re-derived for every trace envelope,
  and symmetric walk/crouch/swim pair clearance plus midpoint grounding
  are evaluated once per unordered node pair. Trace results are unchanged.
- **GL model preparation:** MDL/MD3/MD4 pose-interpolation caches now
  persist across presented frames (like the existing MD2 cache) instead of
  being rebuilt every frame, legacy material batches allocate one color
  per vertex instead of two, model append builds local and world vertices
  in one fused pass, and the GL backend caches packed geometry for the
  stable vertex arrays of world batch templates. Quake II rerelease GL
  median frame time drops from about 77 ms to about 58–64 ms at 640×480
  on the development laptop; a mixed Q2-rerelease/Q1-monsters/Q3-player
  setup improves by a similar margin.
- Navigation eligibility is always read live again: the revision-keyed
  cache introduced with trace-bounded lookup could go stale when doors
  or hurt triggers toggled within a tick. The nearest-first bounded scan
  that fixed the original hang is retained.

The binary download targets Linux x64. Extract
`quake-anthology-1.2.2-linux-x64.tar.gz` and run `./quake-typescript`
with your own game data (see the README for discovery options).

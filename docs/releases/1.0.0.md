# Quake Anthology 1.0.0

First release of the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content.

## Included

- Game and expansion selection, plus custom combinations of worlds, movement,
  characters, weapons, monsters, and equipment.
- Individual mod controls and simultaneous cross-game components through the
  supported QuakeC, native gamecode, and QVM interfaces.
- Shared rendering, audio, input, console, menus, campaign travel, saves, and
  multiplayer services, with classic and rerelease behavior kept separate.
- Level-entry autosaves. Periodic and mid-level autosaves are disabled. Manual
  save/load behavior is unchanged.
- Startup configuration can disable autosaving before a level loads.
- `--version` reports the installed application version.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.0.0-linux-x64.tar.gz`,
open its directory, and run:

```sh
./quake-typescript --content-root /path/to/qfiles --menu --renderer gl
```

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

## Known issue and scope

Native DLL gameplay can still suffer low frame rates and stalls. The lag fix is
scheduled for a patch release. The latest accepted runtime's late base1 sample
measured 41.23 ms in native execution and 45.55 ms per application step against
a 25 ms native interval. This is a simulation measurement, not a rendered FPS claim.

Saving and loading are accepted for this release. Mod compatibility requires
supported executable interfaces and component declarations; discovering a package
does not prove compatibility. See [mod compatibility](../mod-compatibility.md).
The approved ranking-service extension point remains available for a future backend.

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.0.0`
in the repository. Game data retains its original licensing.

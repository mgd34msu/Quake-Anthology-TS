# Quake Anthology 1.2.1

Unified-hosting and performance patch for the shared TypeScript engine for
Quake, Quake II, Quake III, their expansions, and supported rerelease content.

## Unified hosting

- **Every TS source can now host every authored map family.** Foreign Q1 and
  Q2 maps run on any TypeScript primary (Q1, Q2, or Q3) through world
  adjuncts: the authored family's own foundation spawns, steps, and
  checkpoints the classes the primary has no spawns for, while the selected
  primary keeps players and match rules. Adjunct monsters fight, movers run,
  and saves restore the combined world.
- **Q3-authored maps are playable on Q1 and Q2 primaries.** Q3 items
  (weapons, ammo, health, armor, powerups, holdables) spawn through each
  primary's own pickup system and grant through the shared Q3 supply
  profiles, so a railgun pickup on `q3dm17` under Quake gives the super
  nailgun, and a plasmagun on `q3dm1` under Quake II gives the
  hyperblaster. Q3 world classes — jump pads, teleporters, timers,
  speakers, bobbing and static brushes, powerup removers — function on
  both primaries, including haste, regeneration, flight, and
  invisibility timers.
- **Selected foreign enemies fight on guest worlds.** QuakeC and QVM guest
  programs host selected TS monsters as thinking adjuncts or qualified
  combat projections, with save/load support.

## What's faster

- **Row-parallel CPU rasterization.** Large triangle batches are split
  into disjoint row bands across a worker pool with shared framebuffers.
  Rows are disjoint and draw order per pixel is unchanged, so output is
  bit-identical to the serial kernel (covered by an exactness test,
  including fragment-lit shadow batches). `QTS_CPU_WORKERS` controls the
  pool (default: available parallelism − 1, capped at 4; `0` disables).
- **Repeat-wrap sampler hot path.** Bilinear repeat sampling — the
  dominant CPU kernel cost — runs in a dedicated function with
  power-of-two index masks; arithmetic and evaluation order are
  unchanged. Quake classic CPU median frame time drops about 9%.
- **Shared model geometry.** Interpolated pose geometry and
  world-transformed vertices are cached and shared between camera and
  shadow passes instead of recomputed per pass.
- **Cheaper uploads and material setup.** Direct typed-array mip
  generation/resampling with composed gamma tables, a fast path for
  8-bit non-interlaced PNGs, hoisted per-vertex material constants, and
  cached fragment-lit world batch templates with per-frame light
  rebinding.

## Measured

640×480 CPU renderer, `tools/profile-frame.ts`, median frame time on a
quiet machine (serial kernel unless noted):

- Quake classic: ~129 ms → ~118 ms (workers ×4: ~112 ms)
- Quake rerelease: ~162 ms
- Quake II classic: ~122 ms (workers ×4: ~115 ms)
- Quake II rerelease: ~411 ms CPU, ~65 ms GL — shadow-atlas passes stay
  on the main thread; GL remains the default renderer
- Quake III: ~125 ms

## Fixed

- Row-parallel workers crashed on fragment-lit batches because lighting
  registrations carried a non-cloneable resource identity across
  `postMessage`; registrations are now serialized to plain data.
- Constructed-graph bot area lookup on foreign maps could trace every
  navigation node per query; it is now nearest-first and trace-bounded.
  Navigation eligibility is always read live, so doors and hurt triggers
  that toggle mid-tick route correctly.
- Guest enemy replacements relocate correctly even without an authored
  species record, and combat traits write through to QVM guest fields.

The binary download targets Linux x64. Extract
`quake-anthology-1.2.1-linux-x64.tar.gz` and run `./quake-typescript`
with your own game data (see the README content layout).

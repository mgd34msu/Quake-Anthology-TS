# Quake Anthology 1.2.5

Performance patch completing the retained-geometry follow-through from
1.2.4: retained model geometry now feeds stable batches into the GL
pack cache, and the CPU rasterizer stops re-snapshotting and
re-validating every draw.

## What's faster

Measured on the development laptop; your mileage will vary.

- **Stable model batches for the GL pack cache.** The GL buffer packer
  caches packed vertex arrays by identity, but model draws rebuilt
  their batch vertices every frame through CPU projection, so the pack
  cache could never hit for models. Legacy-material models now emit
  world-space batches under the same conditions as world surfaces and
  cache them per retained geometry; shadow world-position/normal
  arrays and shade-divided vertices are likewise shared by identity.
  While a model's retained geometry repeats — frozen or static
  models, multi-seat views of the same frame — its vertices are mapped
  and packed once instead of every frame. Animated poses interpolate
  to fresh geometry each frame and are unaffected (the cross-game GL
  mix of a Q2 rerelease world, Q1 rerelease monsters, and a Q3 player
  measured 64.3 ms median with the cache vs 65.0 ms without,
  back-to-back).
- **CPU: one snapshot per draw, memoized validation.** Source-stage
  draws previously snapshotted their batch and then snapshotted the
  snapshot again inside prepare, discarding the second copy. Draws
  now snapshot exactly once. The per-prepare index-range and
  fragment-attribute finiteness scans are pure functions of immutable
  input arrays and are memoized by array identity (the same contract
  the GL packer's index validation already relied on). In the Q2
  rerelease CPU profile, prepare self time dropped from 3.5% to 2.8%
  and out of the top-20 totals; overall CPU frame time remains bound
  by the triangle kernel (median ~440 ms in that scene at 960x600 —
  GL remains the recommended renderer for rerelease shadow scenes).

## Notes

- No rendering output changes: every cache here is keyed on the exact
  inputs of the computation it skips, and a miss runs the identical
  original code path.

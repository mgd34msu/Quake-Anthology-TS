# Quake Anthology 1.2.3

Console/cvar correctness fix and performance patch for the shared
TypeScript engine for Quake, Quake II, Quake III, their expansions, and
supported rerelease content.

## Fixed

- **`quit` works from every console again.** It was registered only on a
  throwaway startup buffer, so the live console either reported
  `Unknown command "quit"` (Q1 dialects) or forwarded it as chat (Q2).
  `connect`/`disconnect` had the same gap.
- **Shared settings resolve on every console path.** `gamma`, `volume`,
  UI preferences, and the other shared settings reported
  `Unknown command` on dedicated servers and during dedicated config
  execution: the shared-settings registry was never constructed in
  dedicated mode, and source/dedicated command buffers never consulted
  it. The registry is renderer-independent and is now built in all
  modes and consulted by all buffers.
- **`crosshair` exists again** as an alias of the seat-1 crosshair
  preference; it was registered nowhere ("Unknown command" everywhere).

## What's faster

Measured on the development laptop; your mileage will vary.

- **Mixed cross-game GL (Q2 rerelease world, Q1 rerelease monsters,
  Q3 player/weapons): median frame in the 60 ms range**, down from
  ~64–77 ms before this cycle's submission, lighting, and shadow
  signature cuts (per-batch resolver/uniform overhead removed, index
  validation cached, shadow change detection no longer stringifies
  per light per frame, digests hashed through a typed-array pun, and
  never-hitting identity caches no longer charged per MD5 vertex).
- **Q2 rerelease CPU rendering: ~441 ms → ~382 ms median**, from a
  depth-only kernel path for shadow-atlas passes, batch-invariant
  triangle-setup hoisting, shared setup lighting for vertex-lit
  batches, and the row-pool coordinator rasterizing bands itself
  instead of idling at the barrier.
- **Foreign-map bot navigation construction: ~31 s → ~18.5 s** on top
  of 1.2.2's improvements, from memoized ground probes (adjacent
  faces publish duplicate candidates), precomputed cap-sort angles,
  and split-child bounds accumulated during BSP clipping instead of
  a second full vertex pass.

One behavior note, unchanged from before but now visible: the engine's
own saved shared settings (`images.cfg`) are applied after legacy game
`config.cfg`, so for shared preferences the saved store wins over a
hand-edited game config. Console writes always apply immediately.

The binary download targets Linux x64. Extract
`quake-anthology-1.2.3-linux-x64.tar.gz` and run `./quake-typescript`
with your own game data (see the README for discovery options).

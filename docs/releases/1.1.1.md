# Quake Anthology 1.1.1

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. This release fixes
ChatGPT subscription sign-in for the LLM integration.

## Fixed

- LLM subscription sign-in failed when the browser redirected back to the
  local callback listener. The listener ran on the game thread, so while the
  browser was in front and the game was busy in native rendering work, the
  callback connection was accepted but never answered and sign-in stalled
  until it timed out. The loopback callback now runs on its own worker
  thread and answers the browser regardless of game-thread state; the code
  is exchanged for tokens when the game thread resumes. Cancellation and
  timeout also close the listener cleanly instead of leaving its port open.
- LLM credentials could not be saved (`Could not save chatgpt.key.`) when the
  executable lived in a read-only folder, because settings were written next
  to the executable. They now live with the other shared user settings in
  `~/.local/share/quake-typescript/settings`, with existing files migrated
  from the old location on first run.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.1-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

## Known issue and scope

Native DLL gameplay can still suffer low frame rates and stalls, as in 1.1.0.
That remaining performance work is scheduled for a later release.

Saving and loading are accepted for this release. Mod compatibility requires
supported executable interfaces and component declarations; discovering a package
does not prove compatibility. See [mod compatibility](../mod-compatibility.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.1`
in the repository. Game data retains its original licensing.

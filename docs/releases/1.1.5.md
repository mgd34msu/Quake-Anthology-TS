# Quake Anthology 1.1.5

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. This release finishes the
PvP mode matrix left open in 1.1.4, restores retail rerelease saves, and makes
the first measured performance pass across renderers and boot.

## Highlights

- Loki's Minions CTF and Rogue DeathBall now play on every game, as modes of
  their own: flags, runes, the ball, goals, and team scoring run on Quake and
  Quake III worlds, including the haste rune's weapon speedup in each arsenal
  (doubled weapon cycle on Quake weapons, each other arsenal's own haste
  response). Objectives synthesize from deathmatch spawns when a map has no
  authored mode entities.
- Capture the Flag, LMCTF, Tag, and DeathBall are their own PvP modes
  everywhere, not deathmatch variants: selecting one starts the match, with
  no separate deathmatch selection anywhere in the launcher or options.
- Generic Capture the Flag now plays on Quake worlds through the Threewave
  program.
- Retail Quake II rerelease (KEX) transition saves restore at the destination
  map (verified against a Steam save). Quake II horde checkpoints restore,
  and Dimension of the Machine horde wave state survives save and restore.
- Add-ons and saves are found in both the game directory and the rerelease
  directory, with Steam/Nightdive installations searched at the lowest
  priority (local files win).

## Performance

Measured with `tools/profile-frame.ts` on the profile machine; all changes are
pixel-identical under the render suite (423k expectations).

- GL vertex packing, shadow-atlas validation, and shadow projection were
  streamlined: Quake II rerelease median frame time at 640x480 GL dropped
  from about 121 ms to about 96 ms.
- The CPU renderer's per-fragment Quake II lighting skips out-of-range and
  zero-contribution lights before sampling shadows: about 513 ms to 445 ms
  median at 320x240 on the same map.
- CPU rasterizer sampling and vertex flow, clip-plane evaluation, numeric
  operator caching, shadow digest speed, and model vertex-light caching by
  alias-normal table index.
- PNG and JPEG decoding plus the shared binary reader were tightened:
  Quake II rerelease boot from about 6.2 s to about 5.5 s.

## Fixed

- A mismatched external `.lit` from another game directory (for example
  id1's `start.lit` found beside qdoom's `start.bsp`) no longer refuses the
  map; like the source engines, it is ignored in favor of the BSP's own
  lighting. Retail WAVs whose RIFF size understates the file, QC programs
  declaring fewer than sixteen spawn parms, and truecolor replacement sky
  textures are likewise accepted (the qdoom add-on now boots and plays end
  to end).
- A failed game launch no longer leaves the menu with the mouse captured;
  the frontend regains menu focus and releases relative mouse mode.
- Classic Capture the Flag players no longer spawn at -99 health (team
  spelling inside the lock check), and the `ctfstart` lobby is recognized.
- The 1998 retail Xatrix (The Reckoning) combat numbers now come from a
  disassembly-derived second profile, selected by the game library digest.
- The orphaned Q3-ballistics presentation channel was retired; selected
  Quake III weapons execute solely through the original Quake III runtime.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.5-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

## Known issue and scope

Presentation remains the frame-time bottleneck: Quake II rerelease with
fragment lighting and shadow maps is still heavy in both renderers (about
96 ms GL / 445 ms CPU median on the profile machine at low resolution),
and native DLL gameplay can suffer stalls, as in 1.1.4. The HUD is still
the unified HUD rather than each game's native HUD.

Foreign Tag, LMCTF, and DeathBall match state (token, flags, runes, ball)
is not yet part of saved games. KEX Quake II saves restore transition
saves; mid-level KEX saves are refused rather than partially restored.
QuakeWorld expansion products are catalogued but their launches are not
yet verified against retail QuakeWorld data.

Saving and loading are accepted for this release. Mod compatibility requires
supported executable interfaces and component declarations; discovering a package
does not prove compatibility. See [mod compatibility](../mod-compatibility.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.5`
in the repository. Game data retains its original licensing.

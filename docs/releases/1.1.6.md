# Quake Anthology 1.1.6

Patch release for the shared TypeScript engine for Quake, Quake II, Quake III,
their expansions, and supported rerelease content. This release generalizes
the 1.1.5 mismatched-`.lit` fix into one engine-wide rule: an optional
companion or user-owned file that cannot be decoded behaves exactly like the
absent one every loader already admits — as in the source engines — instead
of refusing the map, the match, or the boot.

## Fixed

- A stale or foreign bot navigation file (an `.aas` whose checksum belongs
  to another build of the map, or a corrupt `.nav`) no longer fails the game
  load; bots fall back to constructed navigation, as botlib intends.
- Sounds and music tracks that cannot be decoded register as unavailable
  (the existing warning plus silence), and a broken first-choice voice no
  longer masks the fallback voice.
- A texture candidate that cannot be decoded falls through to the next
  extension in turn, like the source engines' image search; an undecodable
  original beneath a replacement keeps the loaded image's logical size.
- A shader script that cannot be lexed at all (foreign encoding, binary
  garbage) contributes no shaders instead of aborting provider load.
- A shader videomap whose video is absent or undecodable falls back to the
  default image; Quake III UI cinematics report unavailable (-1); a campaign
  cinematic that cannot be played is reported and skipped to the next stop,
  so a missing `.cin`/`.ogv` never blocks campaign progression. A failed
  destination load still keeps the current world.
- Malformed `.arena` files, and arena rows without a usable map, are skipped
  with the rest of the catalog intact.
- User documents that are not JSON at all — seat/gyro/tuning settings, audio
  preferences, server profiles, view preferences, cvar archives, saved
  server lists, the browser cache, torn player progress — load as absent
  (defaults) instead of failing the boot or the browser. Documents that
  parse but fail validation still reject loudly, as before.
- A malformed default sound-environments file and an unparsable authored
  `animation.cfg` now fall back with a printed warning (default footsteps
  match `CG_ParseAnimationFile`).
- A remote seat retired while its view was still binding could escape the
  frame step as an "Application content is closed" error; it now ends
  quietly, like the closed-seat guard at bind entry.

Staged replacement and menu-font loaders remain strict: explicitly enabling
replacement content (enhanced models, texture overrides) still rejects a
malformed replacement atomically, leaving the live scene untouched.

## Download and run

The binary download targets Linux x64. Extract `quake-anthology-1.1.6-linux-x64.tar.gz`
next to your game folders (or anywhere under them), open its directory, and run:

```sh
./quake-typescript --menu --renderer gl
```

The executable finds `id1`, `baseq2`, and `baseq3` in its own folder, the
folder above, or Steam libraries. Use `--content-root /path/to/games` to
point at a specific collection, or `--steam` to search Steam first.

The executable includes Bun. Install SDL2, OpenGL, FreeType, libvorbisfile, and
libtheoradec. Supply your own game files; no retail game data is included.
See [setup](../getting-started.md) and [content layout](../content-layout.md).

## Known issue and scope

Presentation remains the frame-time bottleneck: Quake II rerelease with
fragment lighting and shadow maps is still heavy in both renderers (about
96 ms GL / 445 ms CPU median on the profile machine at low resolution),
and native DLL gameplay can suffer stalls, as in 1.1.5. The HUD is still
the unified HUD rather than each game's native HUD.

Foreign Tag, LMCTF, and DeathBall match state (token, flags, runes, ball)
is not yet part of saved games. KEX Quake II saves restore transition
saves; mid-level KEX saves are refused rather than partially restored.
QuakeWorld expansion products are catalogued but their launches are not
yet verified against retail QuakeWorld data.

Saving and loading are accepted for this release. Mod compatibility requires
supported executable interfaces and component declarations; discovering a package
does not prove compatibility. See [mod compatibility](../mod-compatibility.md).

Engine source is GPL-2.0-or-later. The source for this release is tagged `v1.1.6`
in the repository. Game data retains its original licensing.

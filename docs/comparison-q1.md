- `verification/features/q1.json` preserves **180 requirements**: donor status 108 implemented, 62 partial, 10 missing. All 180 target statuses still say `required`; these historical labels do not describe current completion.

Catalog resource resolution and full parsing of 35 ordinary RR MDL models were also checked. These are bounded witnesses, not a census of every creature encounter.
- Other tests named below are **located test targets**, not newly executed proof. Previously reported results outside these witnesses require their immutable checkpoint/report before acceptance.
- Shared ownership of actors, collision, damage, inventory and resource provenance is the selected architecture. It is not evidence that one donor algorithm is universally superior. Renderer performance, audio quality and numeric equivalence choices remain provisional without a comparative run.
- Map geometry, liquids, hazards, movers, targets, mission scripts and jump pads remain owned by the authored map program. Selecting a creature, weapon or movement policy must not silently translate those map features. Surgical map mixing is a separate deferred capability.

## Current overlap decisions and open universal joins

`docs/reference-contracts.md` RC01–RC10 already records source comparisons for numeric primitives, command/cvar behavior, filesystem, network encoding, entity lifetime, spatial callbacks, resource ownership, rendering and media. These are design decisions to validate, not an automatic Q3-wins rule. Q1's hulls, QC ABI, local-seat ownership, controller response, localized text, source movers and replacement-model rules remain useful shared-engine inputs. Renderer/DSP superiority is explicitly unproven here.

Concrete limitations found or corroborated during this audit:

1. **Selection UI is narrower than the composition goal.** `app/bootstrap/startup-selection.ts` marks same-family alternate-edition/campaign weapons unavailable; independent pickup selection is not supplied by that UI. Preserve useful Q1 mechanics as independently selectable policies instead of claiming the full selection matrix already works.
2. **QC is an unproven application join.** A real executor and save adapter exist, but the production constructor path was not located. This is a higher-priority compatibility gap than adding more catalogue names.
3. **Media is not universally joined.** Root's common audit located cinematic application use in the Q3 UI path, with looping/silent settings. CIN/RoQ modules and Q1 ending text do not establish universal cinematic playback; RC10 also retains missing OGV as work.
4. **Haptics, captions and environmental reverb need actual application consumers.** Input/controller/settings or DSP source alone is insufficient; root's common audit found no application constructors for haptics/captions and no reverb environment integration beyond definition. Gyro has an actual router branch, but physical device proof is still missing.
5. **The feature ledger needs reconciliation, not deletion.** The donor's ten `missing` rows include TS gameplay, gyro and weapon wheel, for which unified source now exists; others remain unknown or blocked. Conversely, source-present APIs cannot be checked complete because their filenames resemble a donor.
6. **Campaign and mixed-mode completeness remain open.** The recent authored-map tests are useful regression anchors; they do not cover all original hazards, jump pads, target chains, bosses, expansions, difficulty modes, local seats or remote clients.

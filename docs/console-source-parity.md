# Console source comparison

Installed source is `d1b437e706e321772da421dbac4dcc75f5a886d2`. This checklist compares command and cvar behavior with the primary Q1, Q2 and Q3 TypeScript donors, including QW, expansions and Team Arena where their source defines a contract. It is a partial semantic comparison, not a new audit of the historical 477-item feature ledger. Registration counts and matching names do not establish working commands.

A family is complete only when its public command accepts the source syntax, queries useful current values, observes caller authority and changes the correct live owner. Defaults, flags, persistence, selected-content behavior and feedback need actual user-flow evidence. Shared implementations may fulfill several donors without duplicating their state.

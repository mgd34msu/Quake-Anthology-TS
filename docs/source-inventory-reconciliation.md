# Source inventory reconciliation

This checklist joins the concrete leads from the [Q1](../verification/integration-candidates/q1/report.md), [Q2](../verification/integration-candidates/q2/findings.md) and [Q3](../verification/integration-candidates/q3/report.md) declaration reports with the earlier [Q1](comparison-q1.md), [Q2](comparison-q2.md) and [Q3](comparison-q3.md) comparisons and their feature inventories: [180 Q1 requirements](../verification/features/q1.json), [193 Q2 requirements](../verification/features/q2.json), [104 Q3 requirements](../verification/features/q3.json).

The extraction uses unified commit `3dc9ca6ca404dc4522ab9e9669fff458805b0993` and each report's pinned donor commit. It preserves source, tests, tools, declarations, local variables, parameters and import bindings. Exact names, signatures, hashes and source-line overlaps identify review candidates; they do not prove equivalent behavior. All unmatched and ambiguous records remain in the raw artifacts. This is a bounded caller review, not an exhaustive semantic audit, and it does not change the 477 requirement IDs or completion totals.

Donor paths below belong to the named game's donor checkout; unified paths belong to this repository. “New omission” means no explicit requirement/source anchor for that capability was identified in the existing inventory. Broad rendering, networking or configuration requirements may still be its eventual parent. The next implementation should extend shared engine services across games, preserving source-visible policy where needed.

## Reproducible complete records

Run the per-game commands in the linked declaration reports, then:

```sh
bun tools/inventory/merge-integration-candidates.ts --input /tmp --out /tmp/quake-integration-combined
```

`/tmp/quake-integration-combined/combined.json` joins all 477 original feature rows, pins all three comparison documents, and references every full declaration/candidate/anchor/historical artifact by path and SHA-256. Broad import/name groups and declarations without feature anchors remain available for deeper review. Historical verdicts remain separate. The checklist above neither exhausts those records nor claims behavioral completeness.

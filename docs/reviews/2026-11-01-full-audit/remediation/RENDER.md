# RENDER remediation
| ID | status | note |
|---|---|---|
| RENDER-005 | fixed | `shaderTableIndex` now returns 0 for out-of-range or non-finite phases (the x86 integer-indefinite masked result) instead of throwing; `evaluateTexCoords` maps non-finite results to 0. Tests: tests/materials/materials.test.ts "shader numeric edge cases". |
| RENDER-002 | fixed | Worker registrations were already per job. Added stable keys: mip level storage is sent once (keyed by level identity, which is replaced on update), textures reference level ids, LRU eviction at a 96 MB budget with evict lists to workers; shadow-atlas depth levels are SharedArrayBuffer-backed so in-place updates reach workers (also RENDER-012). Lighting stays per-job. Test: tests/render/cpu/row-parallel-registry.test.ts (level sent once across 21 jobs, no stale pixels after update). |
| RENDER-012 | fixed | CPU shadow-atlas levels are now SharedArrayBuffer-backed, so workers see in-place atlas updates (textures.ts). No dedicated test (the worker/coordinator drift needs a shadowed multi-job scene); covered only by the existing row-parallel bit-identity tests. |
| RENDER-001 | fixed | New PoseLru (src/formats/q12-model/pose-lru.ts), a total-entry-capped recency cache keyed by frame identity plus lerp, now backs alias interpolation, MDL, MD2, MD3 and MD4 pose caches; world/lit caches are weakly keyed on those poses so they die with eviction. Test: tests/formats/q12-model/pose-lru.test.ts. |
| RENDER-004 | fixed | WireEncoder/WireDecoder carry batch `space` and view `viewProjection`. Test: tests/render/worker-protocol.test.ts "world-space batches and the view projection cross the wire". |
| RENDER-006 | fixed | Legacy blended surfaces (sort class 9) are reversed to back to front in prepareWorldOperations. Test: tests/render/commands/world-translucent-order.test.ts (fails with the old order). |
| RENDER-014 | fixed | prepareWorldOperations checks its cache before traversing; the visibility result is shared with prepareView and the portal scan through the per-view admission (`worldVisibility`). No test. |
| RENDER-018 | fixed | releaseImages clears legacyBatchCache and fragmentBatchCache. No test. |
| RENDER-011 | fixed | SceneImageRegistry gains a shared backend epoch bumped by NativeRenderer after vid_restart replay and CPU resize replay; Q2ShadowScene clears its cached signatures when the epoch changes. Test: tests/render/commands/shadows.test.ts. |
| RENDER-010 | fixed | In recover mode a stray top-level brace is skipped (with its braced section for `{`) instead of discarding the script. The addScript catch is unchanged and still silent (no logger in that layer). Test: tests/materials/materials.test.ts "shader script recovery". |
| RENDER-003 | no-action | Refuted by verification (real visibility does not grow the merge trie). |
| RENDER-007 | fixed | Q1 leaf zero (shared solid leaf, never visible) no longer marks the ancestor index unsafe. Test: tests/render/visibility.test.ts Q1 shared-leaf fixture (fails without the fix). |
| RENDER-008 | fixed | New dynamicLightReachesFace (materials/lighting.ts) filters lights per face, so only reached faces rebuild and others keep their cached static lightmap; buildQ1Lightmap writes pixels in place. Test change: tests/render/commands/static-lightmaps.test.ts used an out-of-range light as a cache invalidator; it now uses a reaching zero-colour light. That test passes (5/5). Atlasing lightmaps was not done. |
| RENDER-009 | fixed | Composite glyph component budget (4096 per top-level glyph), CFF charstring operation budget and stack limit, glyph cell clamp (max(64, 4*px)) in rasterizeGlyph and rasterizeColorGlyph, 4096x4096 atlas cap, and buildFontAtlas skips glyphs whose lazy tables throw RangeError. Test: tests/text/truetype.test.ts covers metrics clamp and failing glyph; the composite and CFF budgets have no test. FDArray amplification not addressed. |
| RENDER-013 | fixed | RenderImageJournal no longer snapshots creation content (shares the frontend's immutable image; updates still copied), and the worker wire encoder keeps the original operation for acknowledgment, so the host journal copy and the post-acknowledge re-copy are gone; GL worker journal skip was already done. Backend swap still replays without re-decoding, so no vid_restart slowdown. Test: tests/render/image-journal.test.ts; worker/restart tests skip or need GL here. |
| RENDER-015 | fixed | Sorted material snapshot is cached per material epoch (any handle creation/replace/cancel or size change invalidates), removing the per-view flat-map and sort (material-registrations.ts). Other sites in the finding are unmeasured per-draw allocations left unchanged. tests/render pass. |
| RENDER-016 | fixed | Merged Q2 PVS buffers are cached per cluster pair (stable identity) and the ancestor mark cache keeps 4 entries most-recent-first. Covered only indirectly by tests/render/visibility.test.ts. |
| RENDER-017 | fixed | Encoder drops an image handle when its release is acknowledged; decoder drops it on decoding release-image. Test: tests/render/worker-protocol.test.ts. |
| RENDER-019 | fixed | Registration lookup index for sourceWorldMaterial (invalidated on every sourceRecords mutation) and a registration map in the replacement stage publish(). The registerSource scan over sourceRecords is unchanged. No test; shader-remap/world tests exercise the paths. |
| RENDER-020 | fixed | Depth-atlas target no longer spawns a second pool (earlier); RowParallelPool.tryCreate now reports its failure reason, exposed as SoftwareRenderer.rowPoolFailure, instead of discarding it. Pool start stays lazy: the Atomics.wait freeze is bounded at 30 s and needs a worker load failure the build prevents. No test. |
| RENDER-021 | fixed | GL sky-side disables blend and alpha test; CPU sky-side draws with one/zero blend and no alpha test. No test (GL needs a context). |
| RENDER-022 | fixed | CPU and GL now share one tightly packed row layout; the API is kept because the worker contract and tests use it, so nothing further remains (finding allowed either removal or a single layout). |
| RENDER-023 | fixed | Added tests: wire round trip (space, viewProjection, release), worker registry bound (levels sent once, no stale pixels), pose cache cap, Q1 shared-leaf, stray-brace recovery, translucent order, shadow epoch. No bound test for retained merge runs (RENDER-003 was refuted). |
| RENDER-024 | fixed | Removed the stray `{}` in cullTriangleLights. The two filter branches are textually identical but typed differently (model pass carries fractions), so they stay, with a comment. |

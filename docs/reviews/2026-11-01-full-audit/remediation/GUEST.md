| GUEST-005 | fixed | `fast-arithmetic.ts` adds an allocation-free exact fast path: SSE binary32 and binary64 add/sub/mul/div (scalar and packed) and x87 `D8/DC/DE` register and memory forms in round-to-nearest, using doubles plus the Dekker/Knuth error term for the inexact flag and the C1 round-up bit. x87 precision control 53 and 24 round like the host double (24 only for binary32 operands) and precision 64 is taken only when the result is exact; NaN, infinity, subnormal, out-of-window, directed rounding and unmasked precision exceptions fall back to the rational path before any state changes. `fastBinary32` no longer allocates per call.
